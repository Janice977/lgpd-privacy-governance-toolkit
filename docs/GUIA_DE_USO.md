# Guia de Uso — LGPD Privacy & Governance Toolkit

## 1. Sobre o projeto

Este repositório apresenta materiais de um estudo de caso acadêmico sobre adequação à Lei Geral de Proteção de Dados Pessoais (LGPD).

O cenário envolve a Universidade fictícia Univazada e a análise de um incidente simulado de exposição de dados pessoais.

O objetivo é demonstrar conceitos de privacidade, governança, documentação de tratamentos e medidas de segurança da informação.

## 2. Como explorar os materiais

### Etapa 1 — Conhecer o estudo de caso

Acesse a pasta [Estudo de Caso](../materiais/estudo-de-caso/).

Consulte o documento PIM para compreender o cenário fictício, o contexto acadêmico e os objetivos do trabalho.

### Etapa 2 — Analisar o ROPA

Acesse a pasta [Planilhas](../materiais/planilhas/).

Abra a planilha ROPA para conhecer exemplos de documentação das operações de tratamento de dados pessoais e de mapeamento de riscos.

Observe como essas informações podem apoiar a governança de privacidade.

### Etapa 3 — Examinar as medidas de segurança

Na mesma pasta, consulte a planilha APÊNDICE J — Declaração de Aplicabilidade das Medidas de Segurança.

O documento permite estudar controles e medidas relacionados aos referenciais ISO/IEC 27001 e ISO/IEC 27701.

### Etapa 4 — Ler o artigo de síntese

Acesse o [Artigo de Adequação à LGPD](../artigos/ARTIGO_ADEQUACAO_LGPD.md).

O artigo apresenta conceitos de ROPA, gestão de riscos, controles de segurança, atuação do DPO e resposta a incidentes.

## 3. Ferramentas necessárias

- Microsoft Excel ou software compatível com arquivos XLSX.
- Leitor de documentos PDF.
- Aplicativo para abrir arquivos ZIP.
- Navegador para visualizar arquivos Markdown no GitHub.

## 4. Cuidados na utilização

- Os materiais representam um estudo acadêmico fictício.
- Trabalhe preferencialmente com cópias das planilhas.
- Não utilize os documentos como comprovação de conformidade legal ou certificação.
- Respeite os direitos dos autores dos documentos originais.
- Não insira dados pessoais reais nas planilhas demonstrativas.

## 5. Competências abordadas

Este projeto permite explorar conhecimentos relacionados a:

- Lei Geral de Proteção de Dados Pessoais (LGPD).
- Registro de Operações de Tratamento (ROPA).
- Governança de dados e privacidade.
- Segurança da Informação.
- Gestão e avaliação de riscos.
- Controles de segurança.
- Fundamentos da atuação do DPO.

## 6. Limitações

Os documentos não constituem uma solução automatizada de compliance, uma auditoria, um parecer jurídico ou uma implementação em ambiente empresarial.

A finalidade do repositório é educacional e de demonstração de conhecimentos acadêmicos.
