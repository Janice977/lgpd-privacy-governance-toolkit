# Checklist de validação antes de publicar ou reutilizar

- [ ] Confirmar que os exemplos são inteiramente fictícios.
- [ ] Verificar se não há dados pessoais em arquivos, comentários, nomes, propriedades ou metadados.
- [ ] Indicar claramente o que é trabalho acadêmico coletivo e o que é extensão demonstrativa de 2026.
- [ ] Conferir a autorização dos coautores para disponibilizar os materiais originais.
- [ ] Revisar fundamentação legal, regulamentos e orientações da ANPD na data de uso.
- [ ] Conferir permissões de acesso, retenção e tratamento de riscos antes de qualquer aplicação real.
- [ ] Testar links relativos e visualização dos CSVs no GitHub.
